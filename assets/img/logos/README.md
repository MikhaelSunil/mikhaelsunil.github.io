# Organisation logos

Drop a logo here and point a row at it in `content/sections.js`:

```js
{ org: "Botnova Robotics", logo: "assets/img/logos/botnova.svg", ... }
```

A row with `logo` uses the image; a row with only `mark` draws a
stencilled monogram instead. Either way the plate is the same size, so
rows stay aligned whether or not every logo is in place.

SVG is best. For a PNG, give it a transparent background and at least
160×160, and trim the whitespace around the glyph or it will look
smaller than its neighbours.

Use logos you have the right to use — generally fine for showing where
you have worked or studied, but it is your call to make, not mine.
